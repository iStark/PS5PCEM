# Horizontal image gathers — October 9, 2026

`IMAGE_GATHER4H` and `IMAGE_GATHER4H_PCK` now execute through PS5PCEM's
shared shader translator and Vulkan resource path. Previously opcode `0x61`
decoded with the horizontal flag but failed the translator's flag validation;
opcode `0x62` was not decoded. This closes shader execution gaps without a
game-specific replacement. Game compatibility and FPS gains are not inferred
from these instruction tests.

## Behavior

- **GATHER4H (`0x61`)** selects one channel with a single DMASK bit and writes
  four consecutive VGPRs. It uses native typed `OpImageGather` with constant
  offsets `(-1,0), (0,0), (1,0), (2,0)`. All offsets are relative to the same
  lower-left footprint texel; native sampler addressing is preserved. This
  follows the [Vulkan gather rules](https://docs.vulkan.org/spec/latest/chapters/textures.html#textures-gather).
- **GATHER4H_PCK (`0x62`)** fetches four texels at base mip level with horizontal
  coordinates `floor(u * width - 0.5) + {-1,0,1,2}` and row
  `floor(v * height)`. Columns clamp to the image edges, negative rows clamp
  to zero, and rows at or past the height return zero. Raw component bits are
  concatenated in texel/channel order, least significant bits first. Set DMASK
  bits select stream words in ascending bit order; exactly `popcount(DMASK)`
  consecutive VGPRs are written. Words beyond the stream are zero. The
  reference's measured behavior for texels wider than 32 bits is zero output.

Coordinate operands are captured before destination writes, including NSA
and overlapping VGPRs. EXEC-disabled lanes and untouched destination words
retain their previous values. The uniform-null-image path also uses the packed
result width rather than incorrectly clearing four registers.

Packed coordinates are clamped before float-to-integer conversion to avoid
overflow for distant coordinates. The lower anchor bound accounts for all
four offsets: an early GPU test caught the last texel incorrectly advancing
to column one for a far-negative U, and the retained test covers that case.
The multiply/subtract remain separate operations at texel-center boundaries.

## Supported subset

| Instruction | Dimensions | Native component formats |
|---|---|---|
| GATHER4H | 2D | R/RG/RGBA: 8-bit UNORM, SNORM, UINT, SINT; 16-bit UNORM, SNORM, UINT, SINT, FLOAT; 32-bit UINT, SINT, FLOAT |
| GATHER4H_PCK | 1D, 2D | R/RG/RGBA: 8/16-bit UNORM, UINT, SINT; 32-bit UINT, SINT, FLOAT. Texels wider than 32 bits take the zero-output path |

Full, direct, identity-swizzled color descriptors and normalized coordinates
are required. A16, D16, R128, indirect tables, array/cube/MSAA views, compressed
and bitfield formats, sRGB conversion and sampler force-sRGB are explicitly
unsupported here. Packed SNORM and half-float formats are rejected because
their original bits cannot generally be reconstructed from the sampled view.
`IMAGE_GATHER8H_PCK` is outside this change.

The existing UINT/SINT sampled banks introduced for BY/PCK loads are reused.
Native views for additional integer formats are restricted to this typed path;
older float-declared sampling paths keep rejecting them. Format-sensitive
resource and translation keys remain in effect.

## Validation

```powershell
zig build vulkan-smoke -Doptimize=ReleaseSafe -- --gather4h
zig build test-rdna2 -Dtest-filter=MIMG -Doptimize=ReleaseSafe
zig build test-vulkan -Doptimize=ReleaseSafe
```

- **1,242 native GPU dispatches and 635,904 checked result words** pass on the
  RTX 3070 Ti with the Khronos validation layer enabled. The CPU oracle checks
  36 ordinary-gather formats and 27 packed-gather formats, including nine
  wide formats that produce zeros. Cases cover all four channel selectors,
  five packed masks, 1D/2D views, negative and edge coordinates, a coordinate
  immediately below a texel-center boundary, repeat/clamp samplers, NSA,
  aliased destinations and inactive EXEC lanes.
- Integer, packed, float payload and untouched-register results compare
  exactly. Ordinary UNORM gather uses an absolute tolerance of `0.000002`;
  SNORM allows one normalized 16-bit step (`1/32767`) for native gather
  rounding. This tolerance is not applied to packed raw bits.
- **22/22 focused MIMG tests** and **232/232 Vulkan module tests** pass.
  Translation tests cover compute, vertex and fragment stages. GPU execution
  of the new instructions is checked in compute kernels.
- The previous BY2/BY4/PCK2/PCK4 GPU probe still passes all **174 dispatches
  and 178,176 words**. The ordinary gather-LOD probe also passes, including
  two mips, sampler/view LOD bounds and all eight depth comparisons.
- The complete RDNA2 suite passes **267/277**, versus **263/273** at parent
  `0ceb9f4f0ed44cd703694e619b4a0509d3f5b512`. The ten failing test names are
  unchanged, as is the leak in an existing failing FLAT-load test. The full
  suite is not reported as green.

Local logs and test evidence are retained in `out/gather4h-20261009/` and
adjacent `out/gather4h-*-20261009.log` files.
